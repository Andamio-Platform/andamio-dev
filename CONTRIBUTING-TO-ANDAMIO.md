# Contributing to Andamio's public repos

Want to help build Andamio? This is the front door. It points you at Andamio's **public** repositories, shows what's open for contribution, and helps you plug into the right one.

> **Not the same as [CONTRIBUTING.md](CONTRIBUTING.md).** That file is about contributing to *this* repo (andamio-dev — skills, knowledge entries, spec updates). *This* file is about contributing to Andamio's *other* public repos, with andamio-dev acting as the shared map.

## How it works

Andamio's public work happens in each public repo, in that repo's own contribution flow. andamio-dev doesn't own that work — it's a **map and a router**:

- **See what's open.** Each public repo tracks its available work as GitHub issues. Run `/contribute` to see the current open issues live, or browse the repo's issues on GitHub directly.
- **Pick something up.** Read the repo's own `CONTRIBUTING` and `ROADMAP`, take an open issue, and do the work in that repo's own flow. Anyone can contribute — you don't need to be on the Andamio team.
- **File new work.** If you spot something that isn't tracked yet, `/contribute` can file a new issue for you (under your own GitHub account), or you can open one on the repo directly.

Code-quality and security review stay with the **Andamio Development team** on every public repo — being listed here doesn't change who's accountable for the code.

## What this front door does and doesn't show

It reflects only **public** state — what's already visible on the public repos. How work gets prioritized, sequenced, or delegated is coordinated privately and doesn't live here. So this map tells you *what's open* and *how to plug in*, not *what the team thinks you should do first*. Pick what interests you and check the repo's docs.
